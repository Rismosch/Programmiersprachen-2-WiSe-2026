# Simply Typed Lambda Calculus Implementation in Rust

## Requirements

You require a working Rust installation. Follow the instructions here: https://rust-lang.org/learn/get-started/

## Instructions

To run the code, clone the repo with `git` and run the code with `cargo`:

    git clone https://github.com/Rismosch/Programmiersprachen-2-WiSe-2026.git
    cd Programmiersprachen-2-WiSe-2026/typechecker
    cargo run
